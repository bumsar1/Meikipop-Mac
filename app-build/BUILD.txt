BUILDING ON THE ORIGINAL MAC

Requires the existing Python installation and dependencies, Xcode Command Line Tools, a local Meikipop dictionary, downloaded MeikiOCR models, and a configured mining-settings.json in the source root.

Open Terminal in this app-build directory and run:

xcrun swiftc -O -swift-version 5 -target arm64-apple-macosx13.0 ../native/GameAudio.swift -o ../native/GameAudio
python3 prepare.py
PYTHONPATH=.. python3 -m PyInstaller --noconfirm Meikipop.spec
xattr -rd com.apple.FinderInfo dist/Meikipop.app
xattr -rd com.apple.ResourceFork dist/Meikipop.app
codesign --force --deep --sign - dist/Meikipop.app
codesign --verify --deep --strict dist/Meikipop.app

prepare.py uses the existing OCR models in the Hugging Face cache and collects third-party licenses. The spec includes the local dictionary and mining-settings.json. You do not need to rebuild to use the release app.

Packaged self-test without capturing windows or creating Anki notes:
dist/Meikipop.app/Contents/MacOS/Meikipop --self-test /tmp/meikipop-self-test.json
